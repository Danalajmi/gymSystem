# Gym Management System

A Java-based Gym Management System developed using object-oriented programming principles and a graphical user interface (GUI). The system allows gym staff to manage members, employees, personal trainers, workout programmes, and reports efficiently.

---

# Features

## Member Management
- Add new gym members
- Edit member details
- Delete members
- View member information

## Employee Management
- Add new employees
- Edit employee details
- Delete employees

## Trainer Management
- Assign members to personal trainers
- Remove members from trainers
- View members assigned to a trainer

## Reports
- Generate marketing reports

## System Features
- Graphical User Interface (GUI)
- Exception handling
- Persistent data storage
- Default system initialization data
- Separation of business logic and UI logic

---

# Technologies Used

- Java
- Java Swing / JavaFX
- Object-Oriented Programming (OOP)
- UML Design
- File Handling / Serialization

---

# Exception Handling

The system includes exception handling for:
- Invalid user input
- Missing files
- Duplicate IDs
- Empty form fields
- Invalid trainer/member assignments

---

# Data Persistence

The application stores data between program runs using file handling/serialization.

This allows:
- Members to remain saved
- Employees to remain saved
- Trainer assignments to persist
